## 🔄 게임 플로우

1. 태양계 맵 진입 → 행성 선택
2. 문제 표시 + **점 인디케이터** 카운트다운 (5초)
3. 카드 활성화 → 선택 → 정답/오답 피드백 + 토스트 + 소리/진동
4. **다음 →** 버튼으로 진행 (11문제 연속)
5. 결과 판정 → 메달 or 실패
6. 클리어 → 행성 자전 애니메이션 → 맵으로
7. 실패 → 재도전(1번부터) 또는 홈으로

## 🧠 교육적 설계 원칙

### 문제 순서 최적화
- **덧셈** — 앞 두 수의 합이 10의 배수가 되도록 80% 확률로 배치  
  예: `14 + 16 + 7` (14+16=30으로 먼저 계산 가능)
- **곱셈** — 큰 수가 앞에 오도록 정렬  
  예: `8 × 6 × 2` (큰 수 기준으로 접근)

### 점 인디케이터 카운트다운 (숫자 대신 점 5개)

숫자(5, 4, 3, 2, 1) 대신 점 5개가 하나씩 사라지는 방식을 선택했습니다.

연구에 따르면 숫자 카운트다운은 아이에게 **"얼마 안 남았다"는 압박을 직접적으로 전달**해 긴장감과 불안을 높입니다. 반면 점처럼 추상적인 시각 요소는 시간을 부드럽게 체감하게 해줘 **불안을 줄이고 집중을 유지**시킵니다.

> *"Visual timers reduce anticipatory anxiety levels prior to task onset"*  
> — NIH, Time on Their Side: How Visual Timers Affect Anticipatory Anxiety (2025)

또한 점의 개수를 순간적으로 인식하는 **subitizing(수 직관)** 능력은 유아 수학적 사고의 기초로, 수 감각 발달에 도움이 됩니다.

### 힌트 시스템 (선택적)
- 💡 힌트 버튼을 누르면 앞 두 수만 먼저 계산해서 보여줌
- 강제가 아닌 **선택적** 제공 → 스스로 풀고 싶은 의욕 보호

### 점수 시스템 (스피드 보너스)
- 카드 활성화 후 선택까지의 반응 속도로 공식 계산
- 최대 1000점/문제 → 11문제 최대 11,000점
- 큰 숫자를 보는 성취감 → 재도전 동기 부여
